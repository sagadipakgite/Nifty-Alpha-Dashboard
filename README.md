Nifty Alpha Dashboard: The Nifty Alpha Dashboard is a streamlined investment analysis tool designed to evaluate NIFTY 50 stocks using trend indicators, volatility measures, and essential fundamentals. It transforms market data into clear, actionable insights for more confident and disciplined investment decisions.

Features: The dashboard scores each NIFTY 50 stock using indicators such as EMA, RSI, MACD, and ATR, and provides multi-horizon outlooks from short-term to long-term. It generates momentum-driven, balanced, and low-volatility portfolios based on the investor’s risk preference. Users can access interactive charts, fundamentals, expected return estimates, and correlation matrices through a clean and intuitive interface.

Tech Stack: Python, Streamlit, Pandas, NumPy, Plotly, yfinance

Purpose: This project is built to simplify NIFTY 50 analysis and offer a structured, data-driven framework for identifying opportunities and building portfolios. It aims to help investors navigate market movements with clarity and consistency.
